# Gemini Custom Layout & Navigation Sidebar

Google Gemini（https://gemini.google.com/app）の操作性・可読性を向上させる Google Chrome 拡張機能です。

---

## 🌟 主な機能

### 1. 初期画面の入力エリア拡大（画面比率指定）
- Gemini の初期画面（未会話状態）において、入力フォームを画面幅の 80%（`80vw`）、高さの約半分（`45vh`）に自動で拡大表示します。
- 画面中央の見出しテキストを非表示にして作業スペースを確保します。
- メッセージを送信して会話が始まると、回答を見やすくするため自動的に標準のコンパクトなサイズへと戻ります。

### 2. Enter と Ctrl+Enter のキーバインド反転
- **Enter キー**: メッセージを送信せず、エディタ内で改行を挿入。
- **Ctrl + Enter**（Mac の場合は **Cmd + Enter**）: メッセージを即座に送信。

### 3. デュアルタブ・ナビゲーションサイドバー
画面右側に常駐するフローティングパネルから、以下の 2 つの目次をタブ切り替えで利用できます。

#### 📌 「プロンプト」タブ
- 現在のチャット内で送信した自分のプロンプト一覧を時系列順（上が古く、下が新しい）で表示します。
- プロンプトごとに 28 文字前後でトリミング（長文は「…」表記、ホバーで全文ポップアップ）。
- 各項目をクリックすると、本チャット内の該当プロンプト位置へスムーズスクロールします。

#### 📖 「回答見出し」タブ
- 直近の Gemini からの回答に含まれる見出し（**H1 〜 H6**）を自動抽出して構造化インデックスを表示します。
- 見出しレベル（H1〜H6）に応じて段階的にインデントされ、文書構造が一目で把握できます。
- 各見出しをクリックすると、回答内の該当箇所へスムーズスクロールします。
- 新しい回答が生成されるたびに自動で最新内容へ更新されます。

#### ▼ 最下部へジャンプボタン
- サイドバー下部の「▼ 最下部へ」ボタンを押すと、チャットの最新メッセージ・入力枠まで一瞬でスムーズスクロールします。

## 📁 フォルダ構成

```
gemini-custom-extension/
├── manifest.json   # 拡張機能の設定ファイル (Manifest V3)
├── content.css     # レイアウト、サイドバー、インデント調整用 CSS
├── content.js      # キーバインド制御 & プロンプト・見出し抽出 JS
└── README.md       # 本ドキュメント
```

---

## 🚀 導入手順

1. **Google Chrome** を開き、アドレスバーに `chrome://extensions/` と入力してアクセスします。
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチをオンにします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本ファイル（`README.md`、`manifest.json` 等）が入っているフォルダを選択します。
5. [Gemini](https://gemini.google.com/app) にアクセス（既に開いている場合は **F5** キーでリロード）して動作を確認します。

## ⚙️ 各種カスタマイズ

### 入力枠サイズの変更 (`content.css`)
```css
/* 初期画面の横幅を変更したい場合 */
.input-area-container.is-zero-state {
    max-width: 80vw !important; /* お好みの比率に変更 (例: 85vw) */
    width: 80vw !important;
}

/* 初期画面の縦幅を変更したい場合 */
.input-area-container.is-zero-state rich-textarea .ql-editor {
    min-height: 45vh !important; /* お好みの高さに変更 (例: 50vh) */
}
```

### サイドバーの横幅変更 (`content.css`)
```css
#gemini-prompt-sidebar {
    width: 230px; /* 目次の横幅を変更したい場合に調整 */
}
```
