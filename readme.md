# Gemini Custom Layout, Navigation & Markdown Suite

Google Gemini（https://gemini.google.com/app）の操作性・可読性・長文作成体験を劇的に向上させる Google Chrome 拡張機能です。

---

## 🌟 主な機能一覧

### 1. 初期画面の入力エリア拡大（画面比率指定）
- Gemini の初期画面（未会話状態）において、入力フォームを画面幅の 80%（`80vw`）、高さの約半分（`45vh`）に自動で拡大表示します。
- 画面中央の見出しテキストを非表示にし、広々とした作業スペースを確保します。
- 会話が始まると回答の可読性を保つため、自動的に標準のコンパクトなサイズへと戻ります。

### 2. Enter と Ctrl+Enter のキーバインド反転
- **Enter キー**: メッセージを送信せず、エディタ内で改行を挿入。
- **Ctrl + Enter**（Mac の場合は **Cmd + Enter**）: メッセージを即座に送信。
- 日本語 IME の変換確定の Enter は従来通り動作します。
- Markdown エディタ内でも Ctrl/Cmd + Enter で「反映してそのまま送信」できます。

### 3. 📝 多機能 Markdown エディタ（WYSIWYG Hybrid / リアルタイム構文カラー）
入力フォーム左側の「＋」アイコン横にある **📝** ボタンを押すことで、全画面 82% サイズの専用エディタモーダルを起動できます。長文プロンプトや構造化された指示文の推敲に最適です。

- **構文カラーハイライト（キャレットズレ完全防止）**
  - `# 見出し`, `**太字**`, `*斜体*`, `- 箇条書き`, ` ```コード``` ` などの Markdown 記法を維持したまま、リアルタイムにカラー・下線・背景色が反映されます。
  - レイヤー同期構造により、文字入力時のカーソル（キャレット）の縦横ズレがミリ単位で発生しません。
- **ツールバー（ワンクリック挿入）**
  - 見出し（H1〜H3）、太字、斜体、打ち消し線、箇条書き、番号リスト、引用、コードブロックの挿入に対応。選択テキストを自動で囲み装飾します。
- **Smart List Continuation（スマートリスト自動継続）**
  - リスト行（`- `, `* `, `1. ` 等）で Enter を押すと、次の行にも自動でリスト記号・連番が引き継がれます。空行で Enter を押すと自動解除されます。
- **インデント操作（Tab / Shift + Tab）**
  - `Tab` キーで 2 スペース分のインデント、`Shift + Tab` でインデント解除が可能です。
- **誤閉じ防止機能**
  - モーダル外側の背景クリックや `ESC` キーによる誤クローズをブロック。作業中の文章喪失を防止します。
- **選べる 2 つの完了アクション**
  - **「反映して閉じる」**: Gemini の入力枠に Markdown テキストを流し込んでモーダルを閉じます（モデル切替やファイル添付を確認してから送信したい場合）。
  - **「反映してそのまま送信」**: テキストを流し込み、即座に送信ボタンまで自動クリックします。

### 4. デュアルタブ・ナビゲーションサイドバー
画面右側に常駐するフローティングパネルから、2 つの目次をタブ切り替えで利用できます。

#### 📌 「プロンプト」タブ
- 現在のチャット内で送信した自分のプロンプト一覧を時系列順（上が古く、下が新しい）で表示します。
- プロンプトごとに 28 文字前後でトリミング（長文は「…」表記、ホバーで全文ポップアップ）。
- 各項目をクリックすると、本チャット内の該当プロンプト位置へスムーズスクロールします。

#### 📖 「回答見出し」タブ
- 直近の Gemini からの回答に含まれる見出し（**H1 〜 H6**）を自動抽出し、深さに応じてインデントされた構造化インデックスを表示します。
- 見出しをクリックすると、上部固定バーに被らない最適な位置（画面上部）へスムーズスクロールします。
- 会話を追加していくたびに最新の回答内容に合わせて自動更新されます。

#### ▼ 最下部へジャンプボタン
- サイドバー下部の「▼ 最下部へ」ボタンを押すと、メインチャット履歴の最新回答・入力枠まで一瞬でスムーズスクロールします（左サイドバーの履歴位置には干渉しません）。

### 5. 💾 コードブロックの保存場所指定（ダウンロード横取り）
- Gemini が出力したコードブロック右上の「ダウンロード」アイコンをクリックした際、直接ダウンロードフォルダに入るのを防ぎ、必ず OS 標準の **「名前を付けて保存」ダイアログ（保存先指定ウィンドウ）** を表示させます。

## 📁 フォルダ構成

```
gemini-custom-extension/
├── manifest.json   # 拡張機能の設定ファイル (Manifest V3 / downloads権限含む)
├── background.js   # 「名前を付けて保存」ダイアログ制御用 Service Worker
├── content.css     # レイアウト、サイドバー、Markdownエディタ用 CSS
├── js/
│   ├── keybinds.js        # Enter / Ctrl+Enter のキーバインド反転
│   ├── downloader.js      # コード保存時の「名前を付けて保存」強制
│   ├── markdown-modal.js  # Markdownエディタ
│   └── sidebar.js         # プロンプト・見出し目次サイドバー
└── readme.md       # 本ドキュメント
```

## 🚀 導入手順

1. **Google Chrome** を開き、アドレスバーに `chrome://extensions/` と入力してアクセスします。
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチをオンにします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本ファイル一式が入っているフォルダを選択します。
5. [Gemini](https://gemini.google.com/app) にアクセス（既に開いている場合は **F5** キーで再読み込み）して動作を確認します。

## ⚙️ 各種カスタマイズ

### 入力枠サイズの変更 (`content.css`)
```css
/* 初期画面の横幅を変更したい場合 */
.input-area-container.is-zero-state {
    max-width: 80vw !important; /* お好みの比率に変更 (例: 85vw) */
    width: 80vw !important;
}

/* 初期画面の縦幅を変更したい場合 */
.input-area-container.is-zero-state rich-textarea .ql-editor {
    min-height: 45vh !important; /* お好みの高さに変更 (例: 50vh) */
}
```

### 右サイドバーの横幅変更 (`content.css`)
```css
#gemini-prompt-sidebar {
    width: 230px; /* 目次の横幅を変更したい場合に調整 */
}
```
